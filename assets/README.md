# Presentation media

These images and the recording show real browser sessions in Plesk 18.0.82.3 on
Ubuntu 24.04, with the extension at `213ca5e5e29f450b04f5c5cb279033fcdb805f8a`
and Tabularis core at `0d2a6a098f8369653b918d1e78d7f4eeeac65d8a`.
They were captured on 2026-11-16 against the synthetic PostgreSQL and MariaDB
fixtures documented in [the lab validation report](../lab/VALIDATION.md).

The decorative window frame and background follow the Tabularis governance
release-media tools. The video uses a decorative Safari-style frame with a neutral
address bar; the browser capture itself is neither Safari nor macOS. The entire
application viewport remains visible during eased whole-window movements. Long
page-loading waits are shortened in the montage; actual clicks and query results
are unchanged. Screenshots retain
the real panel content; the recording and its poster redact public addresses
and domain identifiers using `plesk.tabularis.local` and `test.tabularis.local`
without changing query results. No login, password,
session cookie or API token is shown.

Only final PNG screenshots, the sanitized MP4/GIF and their JPEG poster belong here.
Private source footage and the separate English/Italian PDF reports stay outside
Git. The source footage must not be copied into a public branch or release.
